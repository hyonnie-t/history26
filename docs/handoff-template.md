# 핸드오프 양식 (모델을 바꿔 새 세션을 열 때)

같은 세션에서 모델을 바꾸면 쌓인 컨텍스트를 처음부터 다시 읽어 사용량이 늘어난다.
바꾸려면 **새 세션**을 열고, 이전 대화 전체 대신 아래 한 장만 첫 메시지로 넣는다. 분량은 20줄 안팎.

## 언제 쓰나
- Sonnet이 같은 문제를 두 번 못 풀었을 때 → Opus 새 세션
- Stop 훅 경고가 같은 이유로 두 번 이상 반복될 때
- 세션이 너무 길어져 느려졌을 때

## 양식 (복사해서 채우기)

```
[작업] 한 문장으로.
[레포] history26 / history26_backend
[안 되는 것] 반복되는 훅 경고 문구 또는 오류 메시지 그대로.
[관련 파일] 파일명 + 함수·id 이름 (줄번호는 쓰지 말 것, 편집마다 밀린다)
  - 
  - 
  - 
[이미 해본 것] 최대 5줄. 시도한 방법과 결과.
[건드리면 안 되는 것] AGENTS.md 절대 규칙 중 이번 작업과 닿는 번호.
[확인 방법] 고친 뒤 무엇으로 통과를 확인할지.
```

## 지킬 것
- 대화 복사·붙여넣기 금지. 위 항목만.
- `index.html`·`code.gs` 전체를 첨부하지 않는다. 함수 이름만 적고 새 세션이 범위만 읽게 한다.
- URL·토큰·학생 정보는 적지 않는다(public 레포, 규칙 6).
