# 수업 설계 철학 (콘텐츠 작업 시 먼저 읽기)

핵심: 설명 줄이고 해석하게 만들되, 사실은 정확하게.

- **절대 원칙**: 확인된 사실만 단언, 불확실하면 "확인 필요"라고 먼저 말한다. 논쟁적 해석은 명시. 그럴듯한 내용으로 빈자리 채우기 금지.
  (학생 화면에 검증 상태를 어떻게 다루는지는 `.claude/rules/student-screen.md` — 라벨이 아니라 반영/대체/삭제.)
- 구조: ①질문으로 시작(바로 설명 금지) → ②탐구 활동(학생이 해석) → ③개념 정리(활동 이후) → ④확장 질문(현재/타시대 연결).
- 활동 3요소 필수: 학생 행동(쓰기/토의/선택/판단) + 사고 요구 질문 + 말로 표현하는 단계.
- Scaffold: 수업 중엔 예시 가능하되 학생이 먼저 써본 뒤 공개(예시=비교 대상, 정답 아님). 수행평가는 scaffold를 낮춘다.
- 글쓰기: 줄거리 요약/느낌 쓰기 금지 → 관점 쓰기, 선택 분석, 현재 연결. 중2 눈높이 구어체.
- Padlet 글쓰기: 정답 있는 구조는 AI 대리작성이 쉬워지므로 차단 — 역할 기반 관점, 선택+이유 구조.
- 역할극/창작: 사료·교과서 근거와 연결하거나 "창작 자료"임을 명시. 창작→분석→직접제작 순서가 기본
  (사료가 교과서에 직접 제시된 경우 사료독해→압축재표현도 유효).
- 게임: 학습 피드백 메커니즘(결과→글쓰기·토의 연결) 필수, 역사적으로 모호한 내용은 구현 전 제거, 힌트는 맥락 단서만.
- 내용 구성: 비교/해석/연결 중 최소 1개.
- **출력은 항상 A(안정형)/B(탐구형)/C(참여형) 2~3안**, 각 안에 목표·핵심질문·활동흐름·학생활동예시·교사개입포인트.

## 확립된 역사 해석 (재확인 불필요)
- 카노사 굴욕 핵심: 파문=종교적 죽음→사회적 매장→봉신 충성서약의 신학적 근거 소멸. 단순 권력다툼 프레임 금지.
- 교황권 궤적: 상승→하락 단일 호선. "카노사→아비뇽 반전" 아님.

## 클리포(Clipo) 루브릭 — 상세 절차는 `clipo-rubric` 스킬
- 구간별 독립 판단, 절대 불가 조건은 전 구간 반복 명시.
- AI 임의 기준(논리성·풍부함·명확성 등) 차단 문구 포함.
- 구간당 예시 2개 이상, 500자 제한.
- A+(최상)는 2단계 확인: 표면체크(다인자연결·반론고려·현재연결 중 1개) + 교육과정 근거
  ("적절하고 타당한 근거를 가지고 역사적 사실에 대해 해석, 판단하기") — A+는 배포용 텍스트에 미포함.
- 중학생 수준 허용적 기준, 감점 기반 구조 선호.

## 세특 작성
- 세특 작성지침·에이전트 프롬프트는 별도 운영(프로젝트 파일 참조, 도구는 sengpt).
- 학생 글 직접 인용 유지, 이중 평가 태그 금지, 과정·기능 태그 1세특당 최대 1회.

## 외부 에듀테크 도구 언급
뤼튼·클래스팅·네이버 웨일 등은 업데이트가 빠르니 직접 확인 전엔 "있을 수 있는데 확인해봐"로만 말한다. 확정처럼 단언 금지.
