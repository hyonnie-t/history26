# 형광펜·문장 고르기 — `highlight-pick`

**무엇**: 글을 조각으로 나눠 눌러 칠하고(최대 2곳), 근거 문장 1~2개를 고른다. 고른 조각은 다음 화면 위 고정 띠에 `<mark>`로 다시 보인다.

**언제 쓰나**: 사료·교과서 글에서 근거를 골라 칠하는 지문 읽기 활동

**나오는 앱**: empire-rebut(형광펜), suffrage_age·vienna_diary(`renderFacts` 사실 고르기), modern_slavery(근거 고르기)

## 기준 구현

`empire-rebut/app.js`의 chunk 렌더(`pickable` + `S.marks` 최대 2곳 + toast), `sentList`, `renderPin`; `style.css`의 `.chunk[aria-checked="true"]`, `.pin mark`.

## 꼭 지킬 것

- 데이터의 `|`는 조각 경계일 뿐이고, 지우면 교과서 원문과 같아야 한다.
- 근거 문장은 마침표 기준으로 묶고 10자 미만은 앞 문장에 붙인다.
- 조각 안 낱말 밑줄 금지(skip).

## 흔한 실수

- 구조를 바꾸고 싶을 만큼 맞는 활동인지 먼저 본다 — «지문 해부형»은 기본 양식이 아니다(스킬 섹션 3).
