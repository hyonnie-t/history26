# clipo-rubric

클리포 AI 채점용 루브릭을 활동지·평가계획 기반으로 초안 생성 → 학생 답안으로 미세 조정 → 배포용 텍스트 블록 출력하는 전 과정 스킬.

> **원본 보관 위치**: 이 파일은 `hyonnie-t/history26` 저장소의 `.claude/skills/clipo-rubric/SKILL.md`가 원본(source of truth)이다.
> claude.ai 개인 스킬로도 동기화해서 채팅방(저장소와 연결 안 된 세션)에서 쓰지만, 실제 수정은 항상 이 파일에서 하고
> 개인 스킬 쪽은 그 결과를 옮겨 반영하는 사본이다 — "개인 스킬 사본 갱신" 섹션 참고.

---

## 전체 워크플로우

```
STEP 1. 활동지 + 평가계획 첨부 → 루브릭 초안 생성
STEP 2. 효니 검토 → 수정 요청 반영
STEP 3. 학생 답안 첨부 → 전체 채점 + 판단 근거
STEP 4. 이견 표시 → 루브릭 미세 조정
STEP 5. 클리포 배포용 텍스트 블록 출력
```

요청이 들어오면 현재 어느 STEP인지 먼저 판단하고 해당 단계부터 진행한다.

---

## STEP 1 — 루브릭 초안 생성

### 입력 확인
첨부 파일에서 아래를 추출한다.
- **활동 조건**: 글자 수 제한, STEP 구조, 필수 포함 요소, 역할/관점 지정 여부
- **평가 요소**: 평가계획서의 평가 항목명, 배점 구조, 급간 수
- **절대 결격 조건 후보**: 글자 수 미달, 필수 STEP 공란, 활동 조건 미준수 등 → 활동에서 직접 추출

급간 수가 명시되지 않으면 확인 후 진행한다. (기본값: 3급간)

### 루브릭 작성 원칙 (전 급간 공통 적용)

**구조 원칙**
- 각 급간은 순서 읽기 없이 독립 판단 가능하도록 작성
- 판단 순서가 필요한 경우 해당 급간 내부에 명시
- 급간 간 중복 표현 최소화

**절대 결격 조건**
- 활동에서 추출한 결격 조건을 **모든 급간 끝**에 동일하게 반복 명시
- 형식: `단, [조건]인 경우 이 점수를 줄 수 없다.`

**AI 임의 기준 차단**
- 논리성, 풍부함, 구체성, 명확성, 완성도 등 주관적 기준은 명시하지 않는 한 루브릭에 포함하지 않는다
- 판단 기준은 활동 조건에서 직접 도출된 것만 사용

**분량 제한**
- 급간당 500자 이내
- 충족 예시 2개 이상 포함 (실제 학생 답안 수준으로 작성)

**허용적 기준**
- 중학생 수준에 맞게 감점 기반 구조 선호
- 완벽한 답보다 조건 충족 여부 중심으로 판단

### 판단+근거형 활동 결격 조건 (선택 + 이유 서술 구조인 활동에 한해 적용)

"게임에서 어떤 선택지를 고르고 그 이유를 서술" 같이 **선택(판단) + 이유** 구조를 요구하는
활동은 아래 세 가지를 절대 결격 조건에 기본으로 포함한다. 활동마다 구체적 예시 문구는
다르게 채우되, 원칙 자체는 활동과 무관하게 고정한다. (근거: 3학년 몽골침략 단원
"강화도 천도 평가하기" 활동에서 이 세 유형으로 오채점된 실사례 검토, 2026-09-01)

**적용 전 확인 — 선택과 서술의 관계 구분**

이 3가지 결격 조건(특히 "선택-이유 불일치")을 적용하기 전에, 이 활동에서 "선택"이 무엇인지부터
구분한다.

- **선택 = 학생의 역사적 판단 그 자체**인 활동(예: "천도는 권력욕이다/항전의지다"를 고르고
  옹호) → 3가지 결격 조건 모두 그대로 적용한다.
- **선택 = 서사 진행 경로(게임 분기)**이고 서술이 그 분기의 정당화가 아니라 **별도의
  종합판단**인 활동(예: 시뮬레이션형 활동에서 엔딩 서술이 이전 차시 판단과의 비교나 전체 흐름에
  대한 판단인 경우) → "선택-이유 불일치" 조건은 적용하지 않는다. 동어반복·막연한 예측 조건은
  그대로 적용한다.

활동 설계 단계(STEP 1)에서 이 구분을 먼저 판정하고 루브릭에 명시한다. (근거: 3학년
"몽골2차시_선택시뮬레이션" 활동에서 엔딩 서술이 게임 분기 정당화가 아니라 1차시 판단과의
비교형 종합판단으로 설계됐는데도 "선택-이유 불일치"가 적용돼 오채점된 실사례 검토,
2026-09-03)

**1) 동어반복(순환논리)**
이유 문장이 선택의 명칭·개념을 그대로 되풀이하거나, 어미·조사만 바꿔("~인거 같다"를
반복하는 식) 사실상 같은 내용을 순환적으로 되풀이할 뿐, 그 선택을 뒷받침하는 독립적인
근거가 없는 경우. **정확히 같은 단어를 재사용한 경우뿐 아니라, 표현만 바꾼 순환논리도
포함**해서 판단한다 — 문구가 다르다는 이유로 통과시키지 않는다.

**2) 선택-이유 불일치**
학생이 고른 판단 범주와 실제로 서술한 이유의 내용이 서로 다른 판단 범주(다른 선택지)를
가리키는 경우. 이 경우는 "경계 사례"로 중간 급간에 남기지 않고 **반드시 최하위 급간으로
판정한다** — 애매하다는 이유로 위쪽 급간에 걸쳐두지 않는다.

**3) 조합 판단 원칙**
이유 문장이 여러 요소로 이루어진 경우, 위 두 결격 조건(동어반복/불일치)에 해당하는 부분이
이유의 **일부에라도** 포함돼 있으면, 나머지 부분에 조건이나 사실 언급이 있어도 그것만으로
상위 급간으로 구제하지 않는다. 결격 조건은 "전체 이유 중 하나라도 해당하면 적용"이 원칙이다.

이 세 조건은 아래 "급간 상향평준화 방지" 원칙과 같은 맥락이다 — 애매하면 아래로, 위로
반올림하지 않는다.

### 급간 상향평준화 방지

"상" 기준이 포괄적으로 작성되면 대부분의 답안이 상으로 몰리는 상향평준화가 발생한다. 아래를 지킨다.

- "상" 기준은 "잘 설명함", "논리적임" 같은 포괄적 표현이 아니라 검증 가능한 구체 조건으로 작성한다.
  예: "역사적 요인을 잘 연결함" (X) → "요인 A와 B를 모두 언급하고 그 인과관계를 한 문장 이상으로 서술함" (O)
- 초안 생성 후 자가 점검한다: 이 조건을 학급 대다수(70% 이상)가 충족할 것 같으면 조건을 더 구체화한다.
- 좁히는 방향은 항목 삭제가 아니라 "구체성 추가"로 한다 (개수 지정, 연결 방식 지정 등).

### 출력 형식

급간별 텍스트 블록으로 출력. 점수 표기 없이 기준문만.

```
[최고 급간명 — 예: 잘함 / A / 상]

(기준문)

충족 예시 1: "..."
충족 예시 2: "..."

단, [결격 조건]인 경우 이 점수를 줄 수 없다.

---

[중간 급간명]

...

---

[최저 급간명]

...
```

급간명은 평가계획서 표기를 따른다. 없으면 상/중/하로 기본 설정하고 확인 요청.

---

## STEP 1-B — 포털 전용 최상위(A+) 판정 (기본 정책, 고정)

클리포에 전송하는 상/중/하 판정과는 별도로, 학습통합포털에서만 쓰는 최상위(A+) 판정 필드를 추가한다. 클리포 배포용 텍스트 블록(STEP 5)에는 포함하지 않는다.

**적용 대상**: "상" 판정을 받은 답안에 한해서만 추가 확인한다.

**2단계 확인 구조** (둘 다 "예"일 때만 A+)

1단계 — 표면 조건 (활동 성격에 맞는 항목만 골라 확인. 어떤 항목이 해당 활동에 맞는지는 STEP 1에서 판단해 표시한다)
- 역사적 요인 2개 이상을 명시적으로 연결했는가
- 반론/다른 관점을 고려했는가
- 현재와의 연결을 제시했는가

2단계 — 근거 확인 (2022 개정 교육과정 '과정·기능' 범주 중 "적절하고 타당한 근거를 가지고 역사적 사실에 대해 해석, 판단하기" 기준. 활동과 무관하게 항상 동일하게 적용하는 고정 문구)
- 1단계에서 확인된 항목이 단순 언급 수준이 아니라, 근거를 바탕으로 한 해석·판단으로 실제 이어졌는가

**출력 형식** ("상" 판정 답안에만 추가)
```
포털 전용 확인:
→ 1단계(표면조건): 예 / 아니오 — 해당 항목: (...)
→ 2단계(근거확인): 예 / 아니오
→ 최종: A+ / 상(유지)
```

**주의**
- 1단계만 충족하고 2단계 미충족이면 A+ 아니고 상 유지. AI가 임의로 완화하지 않는다.
- 이 판정은 포털 기록용이며 클리포 점수 자체에는 영향을 주지 않는다.

## STEP 2 — 수정 요청 반영

수정 요청을 받으면:
1. 변경된 급간만 재출력 (전체 재출력은 명시 요청 시에만)
2. 변경 이유가 루브릭 원칙과 충돌하면 짧게 플래그 표시 후 반영
   - 예: "이 기준은 AI가 '논리성'으로 해석할 수 있어. 더 구체적인 조건으로 바꾸는 게 안전해."

---

## STEP 3 — 학생 답안 채점

학생 답안 파일(스캔 또는 텍스트) 첨부 시:

1. 루브릭 기준으로 전체 답안 채점
2. 각 답안마다 아래 형식으로 출력

```
답안 N
→ 판정: [급간명]
→ 근거: (해당 급간 판단 기준 중 적용된 항목 한 줄)
→ 플래그: 있음 / 없음
   (플래그 있음: 경계 케이스 또는 루브릭 기준 충돌 발생 이유 한 줄)
```

"상" 판정인 경우, STEP 1-B 기준으로 아래를 이어서 출력한다 (중/하 판정에는 출력하지 않음).
```
포털 전용 확인:
→ 1단계(표면조건): 예 / 아니오 — 해당 항목: (...)
→ 2단계(근거확인): 예 / 아니오
→ 최종: A+ / 상(유지)
```

3. 채점 완료 후 요약 출력
```
전체 N건 채점 완료
경계 케이스 / 플래그: N건 (답안 번호 목록)
→ 이견 있는 답안 번호를 알려주면 루브릭 조정 진행할게.
```

**스캔 품질 주의**
글씨 인식이 불가능한 답안은 "판독 불가"로 표시하고 건너뜀.

---

## STEP 4 — 이견 기반 미세 조정

효니가 이견 있는 답안 번호를 표시하면:

1. 해당 답안과 판정 근거를 다시 제시
2. 이견의 원인을 진단
   - 루브릭 기준이 불명확한 경우 → 기준문 수정 제안
   - 결격 조건 누락인 경우 → 결격 조건 추가 제안
   - 예시 답안이 부족한 경우 → 예시 보완 제안
3. 수정안 제시 → 확인 후 반영

---

## STEP 5 — 배포용 텍스트 블록 출력

최종 확정된 루브릭을 클리포 입력용으로 정리 출력.

- 급간별 텍스트 블록 (점수 표기 없이 기준문만)
- 각 블록 사이 구분선
- STEP 1-B의 포털 전용 A+ 판정 기준은 여기 포함하지 않는다 (클리포 입력용이 아님)
- "클리포 입력 준비 완료" 확인 문구로 마무리

## 개인 스킬 사본 갱신 (claude.ai 채팅방용)

이 저장소와 연결되지 않은 채팅방에서도 clipo-rubric을 쓰기 위해 claude.ai 개인 스킬로 별도
등록해둔 사본이 있다. **자동으로 동기화되는 기능은 없다** — 이 파일을 고칠 때마다 수동으로
옮겨야 한다.

- 이 파일을 고칠 일이 생기면(레포에 연결된 세션이든 아니든) **항상 이 파일부터** 수정한다.
  개인 스킬 쪽 화면에서 직접 고치지 않는다 — 그쪽은 세션마다 새로 내려받는 사본이라 그 자리에서
  고쳐도 다음 세션엔 사라진다(2026-09-01 "판단+근거형 활동 결격 조건" 섹션 유실 원인).
- 이 파일이 바뀌면, claude.ai 설정의 개인 스킬 편집 화면(또는 skill-creator 스킬)에 이 파일
  전체 내용을 그대로 붙여넣어 갱신한다. 두 사본의 내용이 100% 같아야 한다 — 요약하거나
  발췌해서 넣지 않는다.
- 저장소에 연결 안 된 채팅방에서 clipo-rubric으로 작업하다가 이 파일에 없는 새 판단 기준이
  필요해졌다면, 그 세션 안에서만 임시로 적용하지 말고 다음에 저장소에 연결된 세션에서 이
  파일에 먼저 반영한 뒤 위 절차로 개인 스킬을 갱신한다.

## 주의사항

- 클리포의 실제 UI·기능은 업데이트가 잦으므로 인터페이스 관련 내용은 단정하지 않는다
- 루브릭 기준은 활동 조건에서 도출된 것만 사용. 임의로 채워 넣지 않는다
- 평가계획서와 활동지가 충돌하는 경우 반드시 확인 요청
